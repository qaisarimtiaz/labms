## STEP 1: CREATE RENDER ACCOUNT (10 min)

### 1.1 Go to Render.com

1. Open your browser (Chrome, Edge, Firefox)
2. Type: **https://www.render.com**
3. Click on **"Sign Up"** button (top right)

### 1.2 Create Account

Choose "**Sign up with GitHub**"

**If you don't have GitHub:**
- Click "**Create GitHub account first**"
- Enter email (example: yourname@gmail.com)
- Create password (something you'll remember)
- Click "Create account"
- GitHub sends verification email → Click link

**If you have GitHub:**
- Login with your GitHub email/password
- Render will connect automatically

### 1.3 Verify Email

- Check your email inbox
- Look for email from Render
- Click the verification link
- ✅ Render account is ready!

## STEP 2: CREATE MONGODB ACCOUNT (10 min)

### 2.1 Go to MongoDB.com

1. Open new browser tab
2. Type: **https://www.mongodb.com/cloud/atlas**
3. Click **"Start Free"** button

### 2.2 Create Account

1. **Email**: Enter your email (same as Render is fine)
2. **Password**: Create a strong password (8+ characters)
3. **Confirm Password**: Type same password again
4. Check the box: "I agree to terms"
5. Click **"Create Account"**

### 2.3 Verify Email

- Check email for MongoDB verification
- Click link in email
- Fill out company info (doesn't matter much):
  - Organization: "Health Inn"
  - Role: "Admin"
  - Click "Continue"

### 2.4 Create Project

- Next page asks "Create a Project"
- Project Name: "Health Inn Lab"
- Click "Create Project"
- Wait for page to load (30 seconds)

## STEP 3: BUY DOMAIN NAME (10 min)

### 3.1 Go to Namecheap

1. Open new browser tab
2. Type: **https://www.namecheap.com**

### 3.2 Search for Domain

1. In search box at top, type your desired name:
   - Example: **lab.healthinn.com.pk**
   - Or: **healthinn-lab.com**
   - Or: **labtests.healthinn.com**

2. Click **"Search"** button

### 3.3 Check Availability

- Green checkmark = Domain is available ✅
- Red X = Domain is taken ❌

If taken, try another name.

### 3.4 Add to Cart

1. Click **"Add to Cart"** on available domain
2. Click **"View Cart"** (top right)
3. You should see 1 year registration

### 3.5 Checkout

1. **Promo Code**: (skip, optional)
2. Click **"Confirm Order"**

### 3.6 Create Namecheap Account

1. Enter **Email** (same as others is fine)
2. Create **Password**
3. Check "I agree to terms"
4. Click "Sign up and Continue"

### 3.7 Add Payment Method

1. **Card Number**: Your debit/credit card number
2. **Expiry Date**: MM/YY (example: 12/25)
3. **CVV**: 3 numbers on back of card
4. Click **"Pay Now"**

### 3.8 Check Email

- Confirmation email should arrive
- Click link to verify
- ✅ Domain is purchased!

1. Go to **MongoDB.com**
2. Click your **profile** (top right)

4. Click **"Add Payment Method"**
5. Enter same credit card:
   - Card Number
   - Expiry Date

## TROUBLESHOOTING

### "Email verification not working?"
- Check spam folder
- Wait 5 minutes and try again
- Request new verification link

### "Domain is too expensive?"
- Try different domain names
- .com is usually cheapest
- .com.pk domains cost similar

### "Card payment rejected?"
- Make sure card is international (can use outside Pakistan)
- Check expiry date is correct
- Call bank to confirm no blocks
- Try different card if available

### "Can't create GitHub account?"
- Use different email if yours is taken
- Make sure password is strong (8+ characters)
- Wait 5 min between attempts

### "Forgot password?"
- Click "Forgot Password" on login page
- Click link in reset email
- Create new password
- Save it in your safe file
